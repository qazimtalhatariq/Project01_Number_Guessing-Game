# CLI-Based Number Guessing Game

## mtt_number_guessing_game

A fun and interactive command-line number guessing game!

## Description

This is a simple number guessing game where the system generates a random number between 0 and 10, and the player tries to guess it. The game provides a hint (whether the number is even or odd) to help the player.

## Installation

1.  Make sure you have Node.js and npm installed on your system.
2.  Install the game globally using npm:

    ```bash
    npm install -g mtt_number_guessing_game
    ```

## How to Play

1.  Once installed, run the game from your terminal:

    ```bash
    npx mtt_number_guessing_game
    ```

2.  The game will greet you with an animated welcome message.
3.  The system will secretly pick a random number between 0 and 10.
4.  You will be given a hint: "Tip: Number is Even" or "Tip: Number is Odd".
5.  You'll be prompted to enter your guess.
6.  The game will then reveal your guess and the number the system generated.
7.  It will tell you if your guess was correct or not.
8.  Finally, it will ask if you want to play again. Choose "Yes" to continue or "No" to exit.
